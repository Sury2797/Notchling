# Support, cancellation and refunds

**Development support:** [GitHub Issues](https://github.com/SuryaK999/Notch-win-linux/issues). Include the app version/commit, Windows edition/build, affected tool, expected behavior and minimal reproduction steps. Remove personal data and secrets. The public issue tracker is not a channel for credentials, card data or private billing records.

**Premium price:** US$2/month, billed monthly once the configured service launches. Both Windows 10 22H2 x64 and supported Windows 11 x64 releases are equal qualification targets. Linux desktop support is not part of the current subscription promise.

## Customer actions after billing launches

| Action | Required channel / behavior |
| --- | --- |
| Cancel renewal | Authenticated billing portal; confirmed paid access lasts to the period end unless a disclosed refund changes it |
| Restore purchase | Authenticated service recovery; never infer paid access from a local flag |
| Request refund | Private authenticated request; proposed first-purchase window is 14 calendar days, subject to mandatory consumer rights |
| Recover local work | Settings export/restore/recovery; available regardless of current tier |
| Uninstall | Save and quit first; installer retains local data and credentials; cancellation is separate |

## Release-blocking owner fields

The maintainer must supply a legal publisher identity/contact, private support channel, authenticated billing portal, regional tax/consumer disclosures, approved refund policy and support response targets before accepting payment. No response-time SLA, jurisdiction, email address or working checkout is invented here.

The proposed refund and subscription policies are in [Product terms](product-terms.md). Data handling is in [Privacy](privacy.md). Commercial configuration and native qualification must be complete before the signed release draft is published.
